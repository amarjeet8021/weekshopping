# Week Shopping

Static shopping website (HTML/CSS/JS) — Clothes, Mobiles, Laptops, Sign In / Sign Up, Cart, Support.

## Vercel par live karna
1. Is `week-shopping` folder ko GitHub repo me push karo.
2. vercel.com -> Add New -> Project -> repo select karo -> Deploy (koi build setting nahi chahiye).
   Ya CLI: `npm i -g vercel` phir folder me `vercel --prod`.

## Notes
- Sign In/Sign Up abhi demo hai (browser localStorage). Real users ke liye backend (Supabase/Firebase) lagana hoga.
- Support email `app.js` me `SUPPORT_EMAIL` se badal sakte ho.
